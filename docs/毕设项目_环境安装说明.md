# 招标审核系统 · 环境安装说明

## 运行环境要求

- Python 3.9（推荐，项目 venv 基于此版本）
- macOS / Windows 均可
- 需要能访问外网（调用 DeepSeek API 和百度 OCR）
- Dify 工作流服务需部署在 `http://localhost`（或修改 app.py 中的地址）

---

## 一、克隆/获取项目

将项目文件夹 `pythonproject` 放到本地任意目录，进入该目录：

```bash
cd /path/to/pythonproject
```

---

## 二、创建虚拟环境

```bash
python3.9 -m venv .venv
```

激活虚拟环境：

```bash
# macOS / Linux
source .venv/bin/activate

# Windows
.venv\Scripts\activate
```

---

## 三、安装依赖

```bash
pip install flask==3.1.3 \
            requests==2.32.5 \
            python-docx==1.2.0 \
            PyPDF2==3.0.1 \
            pymupdf==1.24.0 \
            lxml==6.0.2
```

> **说明：**
> - `pymupdf` 提供 `fitz` 模块，用于 PDF 解析
> - `python-docx` 用于读取 Word 文档
> - `flask` 是 Web 框架主体

---

## 四、配置 API 密钥

打开 `app.py`，找到以下配置项，替换为实际值：

| 变量 | 用途 |
|------|------|
| `DEEPSEEK_API_KEY` | DeepSeek 大模型，招标文件信息识别 |
| `BAIDU_OCR_API_KEY` / `BAIDU_OCR_SECRET_KEY` | 百度 OCR，图片/扫描件识别 |
| `DIFY_RECOGNIZE_API_KEY` 等 | Dify 各工作流密钥 |
| `DIFY_BID_COLLUSION_API_KEY` | 围标串标分析，需先导入 `bid_collusion_workflow.yml` |

---

## 五、启动项目

```bash
python app.py
```

日志会同步写入项目目录下的 `tender_service.log`。

---

## 六、常见问题

**Q：提示 `ModuleNotFoundError: No module named 'fitz'`**  
A：执行 `pip install pymupdf`

**Q：Dify 工作流无响应**  
A：检查 `http://localhost` 是否可访问，或修改 app.py 中的 `DIFY_*_URL`

**Q：百度 OCR 报错**  
A：登录百度智能云控制台，确认 API Key 和 Secret Key 有效，OCR 服务已开通
